# Software environment

The final computational workflow was executed using the following core software environment:

| Software | Version |
|---|---|
| Python | 3.13.1 |
| SLEAP | 1.6.3 |
| SLEAP-NN | 0.2.0 |
| PyTorch | 2.12.1 |
| pandas | 3.0.3 |
| NumPy | 2.5.1 |

SLEAP was used for multi-animal pose estimation and prediction handling. SLEAP-NN and PyTorch provided the neural-network training and inference framework. Subsequent RFID processing, identity reconstruction, quality-control analyses and behavioural calculations were implemented in Python.

The complete virtual environment is not distributed because it contains platform-specific dependencies. Core software versions are reported here to document the computational environment used for the thesis analyses.
